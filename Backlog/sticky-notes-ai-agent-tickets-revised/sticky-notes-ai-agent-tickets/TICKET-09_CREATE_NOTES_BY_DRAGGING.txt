TICKET ID: SN-09
TITLE: Implement armed create mode and drag-to-create note geometry
PRIORITY: BLOCKING / CORE INTERACTION 3
DEPENDS ON: SN-03, SN-05, SN-06
PRIMARY FILES:
- src/features/board/Board.tsx
- src/features/board/useBoardGestures.ts
- src/features/board/Board.css

GOAL
Allow the user to arm a create tool and drag on empty boardSurface space to create a note at the requested position and size.

BOARD TOOL
- Board owns tool state: "select" | "create".
- Default tool is "select".
- Clicking "New note" arms create mode.
- The button must expose aria-pressed.
- Default label: "New note".
- Armed label: "Drag on the board to create".
- Create mode should use a crosshair cursor over boardSurface.

CREATION START RULES
Creation begins only when:
- tool === "create".
- Pointer start passes the primary-left-button gate.
- The user presses the empty boardSurface itself.
- The pointer is not currently over the trash zone.
- No other gesture is active.

Do not begin creation when pointerdown originated from:
- A note.
- Textarea.
- Header.
- Resize handle.
- Trash zone area.
Use currentTarget/target checks or explicit propagation boundaries to enforce empty-surface-only behavior.

START SEQUENCE
1. Measure boardSurface bounds.
2. Convert pointerdown to BoardPoint.
3. Store a creating Gesture with pointerId, pointerOrigin, latestPointer, and boardBounds.
4. Capture the pointer on boardSurface.
5. Do not immediately render a preview.
6. Mark gesture active.

SHORT-DRAG THRESHOLD
Use hasReachedCreateThreshold for both preview and commit.
If movement stays below MIN_CREATE_DRAG_DISTANCE:
- Do not show a creation preview.
- Do not create a note on release.
- Return gesture to idle.
- Keep the create tool armed so the user can try again.

CREATION PREVIEW
On scheduled frames after threshold is reached:
- Calculate createRectFromDrag(pointerOrigin, latestPointer, boardSize).
- Render a pointer-events-none creation preview.
- Support all four drag directions.
- Apply minimum dimensions and board normalization through the shared geometry function.
- Do not create or dispatch a note during pointermove.

COMMIT
On matching pointerup:
1. Recompute release BoardPoint from the event.
2. Recheck the same threshold.
3. If below threshold: commit nothing, clear gesture, keep create tool armed.
4. If threshold reached:
   - Compute final rect with createRectFromDrag.
   - Generate a unique NoteId at the commit boundary. crypto.randomUUID() is appropriate when available; provide a small typed fallback only if required by target browsers/tests.
   - Create Note { id, rect, text: "" }.
   - Dispatch noteAdded.
   - Select the new note.
   - Set pendingFocusId to the new ID.
   - Return tool to "select".
5. Clear preview and capture through the shared terminal path.

CANCELLATION
- Escape while create mode is armed but no gesture is active returns tool to "select".
- Escape during an active creation gesture cancels the gesture and returns tool to "select".
- pointercancel/lost capture cancels the active gesture without creating a note. Keeping the tool armed after pointer cancellation is acceptable if applied consistently; Escape must always disarm it.
- Unmount commits nothing.

CREATION PREVIEW CSS
- pointer-events: none.
- Clearly distinct from committed notes.
- No decorative transition during the gesture.
- Must remain inside boardSurface.

OUT OF SCOPE
- Click-to-create default-sized notes.
- Color selection.
- Note templates.
- Multi-create locking mode after successful creation.

ACCEPTANCE CRITERIA
- Create mode is explicit and accessible.
- Only empty boardSurface starts creation.
- A drag below six pixels creates nothing and shows no preview.
- A valid drag creates exactly one note.
- Reverse-direction drags work.
- Created note is normalized inside the board.
- Created note becomes selected/frontmost and requests textarea focus.
- Successful creation returns tool to select.
- Escape reliably cancels/disarms creation.
- Final geometry comes from pointerup.

MANUAL VERIFICATION
- Try a click without drag.
- Try a 5-pixel drag and a 6+ pixel drag.
- Create in four drag directions near board edges.
- Attempt creation on a note and on trash; nothing should start.
- Fast drag and release before preview frame; final note must still be correct.

DONE WHEN
Drag-to-create is reliable enough to satisfy the core checkpoint independently of movement, resize, and delete.
